================================================================================
  1.  WHAT IS KATSKLUB?
================================================================================

KatsKlub is a full-featured social media / mini-social app built with Flutter
for Android (and web). It combines elements of Instagram (posts, stories,
reels), Facebook (feed, groups, reactions), X/Twitter (hashtags, reposts),
and Discord (DMs, emoji reactions) into a single platform.

The app has its own custom backend server (Node.js/Express at katsklub.top)
running via PM2 as the 'katsklub' process. It supports real-time features
through Socket.IO, push notifications via Firebase, and audio playback with
background support.

Target audience appears to be Filipino users (many comments/documentation
are in Tagalog). The branding uses a coral/orange color scheme and the
Inter font family.

================================================================================
  3.  ARCHITECTURE & ENTRY POINT
================================================================================

The app starts in lib/main.dart with the main() function:

  1. WidgetsFlutterBinding.ensureInitialized()
  2. JustAudioBackground.init()    -- background audio playback
  3. Firebase.initializeApp()      -- push notifications
  4. SystemChrome.setSystemUIOverlayStyle()  -- status bar styling
  5. _configureImageCache()        -- 256MB image cache, 1000 items
  6. configureHttpOverrides()      -- Android HTTP client override
  7. AuthService().getCurrentUser() -- check for persisted session

Then it runs KatsKlubApp, which uses a MultiProvider with:
  - GlobalAudioPlayerService (ChangeNotifier) -- the floating disc player
  - ThemeProvider (ChangeNotifier) -- light/dark mode toggle

The MaterialApp uses:
  - ThemeMode from ThemeProvider
  - Custom light & dark ThemeData with Material 3
  - Inter font family (with emoji fallback: Apple/Noto/Segoe UI/EmojiOne)
  - Primary color: #FFFF7A59 (coral orange)
  - Secondary: #111827 (charcoal black)
  - System UI styling (status bar, nav bar)
  - Text scaling disabled via MediaQuery

If there's a current user -> AppShell (main app with tabs)
If no user -> LoginScreen


================================================================================
  4.  NAVIGATION (AppShell)
================================================================================

lib/screens/app_shell.dart implements a 5-tab bottom navigation layout:

  Tab 0: HOME       -- Main feed + story rings + suggested users
  Tab 1: FEED       -- Discover/explore feed
  Tab 2: POST (+)   -- Opens bottom sheet: "Create post" / "Create story"
  Tab 3: MESSAGES   -- Direct messages (with unread badge)
  Tab 4: PROFILE    -- Current user's profile

Key navigation features:
  - IndexedStack preserves tab state when switching
  - PageStorage preserves scroll positions
  - Back button handling:
      1. If video overlay is open -> close it
      2. If not on Home tab -> switch to Home
      3. If on Home tab -> double-press to exit
  - Push notification deep linking (handles message, post_like, follow, etc.)
  - Full-screen NormalVideoOverlay with local history management
  - GlobalAudioMiniPlayer overlay (floating disc)

================================================================================
  6.  SERVICES (lib/services/)
================================================================================

AUTH_SERVICE (auth_service.dart):
  - Email/password login, phone OTP login, Google Sign-In
  - Multi-step signup flow (start -> send OTP -> complete with profile info)
  - Forgot password flow with OTP verification
  - Session management: token + cookie, memory + SharedPreferences persistence
  - Profile update, featured photo CRUD, link metadata fetching
  - Push notification token registration
  - Country/city lookup (from countriesnow.space API)

FEED_SERVICE (feed_service.dart) -- THE CORE SERVICE:
  This is the largest and most critical service. It handles:

  REST API calls:
    - Feed loading (home, discover, reels, hashtag)
    - Post CRUD (create, edit, delete, hide)
    - Likes, bookmarks, reposts, polls
    - Comments (fetch, create, delete)
    - Stories (fetch, seen)
    - Direct messages (threads, messages, search, group management)
    - Notifications (load, mark read, clear)
    - Search (people, hashtags, posts)
    - User relations (follow/unfollow, followers/following lists)
    - Profile stats

  Real-time (Socket.IO):
    - Live notification delivery & unread counts
    - Live DM messages, thread updates, typing indicators
    - Presence service attachment
    - 30-second notification polling as fallback

  Static streams (broadcast):
    - postCreated, postUpdated, postDeleted, postHidden
    - commentCountChanged
    - profileStatsChanged
    - postcardThemesReset, storyCreated
    - dmMessage, dmThreadUpdated, dmTyping
    - notesUpdated
    - unreadNotificationsNotifier, unreadMessagesNotifier

  Caching:
    - Home feed, discover feed, and stories cached to SharedPreferences
    - Post-specific cache replacement on updates

OTHER SERVICES:
  - GeminiService: Google Gemini AI for generating postcard theme images
  - WalletService: Charm points/transactions
  - PresenceService: Socket-based online indicator
  - PushNotificationService: Firebase FCM + click handling
  - GlobalAudioPlayerService: ChangeNotifier for global music state
  - PromotionsService: Ad management via admin dashboard

  9.  STATE MANAGEMENT
================================================================================

The app uses Provider (ChangeNotifier) for state management:

  Global Providers (MultiProvider):
    - GlobalAudioPlayerService  -- Controls the floating music mini-player
    - ThemeProvider             -- Light/dark mode toggle

  Service-level state:
    - Most services use static streams (StreamController.broadcast())
      for cross-component communication
    - FeedService has many static ValueNotifier and StreamController fields
      that any widget can listen to

  Local state:
    - Screens use StatefulWidget with setState for local UI state
    - PageStorage and IndexedStack for preserving tab state

================================================================================
  11.  KEY FEATURES
================================================================================

  POSTCARD THEMES:
    Users can customize their profiles with visual themes (Sunrise, Ocean,
    Gemini Roger, etc.) that render as decorative gradient headers on post
    cards. Uses ShaderMask for smooth blending. Assets are carefully tuned
    per-theme with specific alignment and crop settings.

  CHARM POINTS SYSTEM:
    10-level charm system based on points:
      Level 1:  < 100     Level 6:  < 3500
      Level 2:  < 300     Level 7:  < 5500
      Level 3:  < 600     Level 8:  < 8000
      Level 4:  < 1000    Level 9:  < 11000
      Level 5:  < 2000    Level 10: 11000+

  PROMOTIONS / ADS:
    Built-in ad system where admins can create sponsored posts that appear
    every 15 posts in the feed. Supports target URLs, custom button text,
    and target profile links.

  MUSIC SYSTEM:
    Full music library with user-created playlists. Users can upload tracks
    or search a library. Global floating mini-player persists across screens.
    Background audio playback via JustAudioBackground.

  GAMES:
    5 built-in casual games: Uno, Memory Match, Flappy Kat, Guess the Song,
    Connect Four. Each has its own dedicated screen with game logic.

  REAL-TIME:
    Socket.IO connection for:
    - Live notification delivery & unread counts
    - Instant DM messaging & typing indicators
    - Online/offline presence indicators
    - Note updates

  PRIVACY:
    Posts can be Public, Friends-only, or Only Me. Profile visibility
    toggles for email, gender, birthday, location, phone, followers,
    and following lists. Private accounts and block/mute support.
