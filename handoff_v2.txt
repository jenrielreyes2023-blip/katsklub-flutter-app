1. SAFETY / MODERATION STACK (HIGHEST PRIORITY)
------------------------------------------------------------------------
Kapag may real users na ang katsklub, ito ang dapat unahin. Walang
mini-social na ligtas kung wala nito.

   1.1 Block / Mute user
       - Block: complete cutoff (hindi makakakita ng posts/profile/dm)
       - Mute: tahimik na hide sa feed without notifying the user
       - Backend: blocks table (blocker_id, blocked_id, created_at)
       - Apply mo sa: feed query, profile view, search, DM, mentions,
         notifications.

   1.2 Report user / post / comment
       - Modal with reason categories (spam, harassment, nudity, etc.)
       - Backend: reports table na nakikita sa admin_dashboard_screen
       - Auto-hide threshold (e.g., 5+ reports = auto-hidden pending review)

   1.3 Private account toggle
       - Profile setting: public vs private
       - Private: kailangan ng follow request before makita ang posts
       - Add follow_requests table at request flow sa notifications

   1.4 Comment controls
       - Per-post setting: who can comment (everyone / followers / no one)
       - Default sa user preference
       - Muted keywords (i-filter comments na may listed words)

   1.5 Account deletion / data export
       - Settings screen: "Delete account" with grace period (e.g., 14 days)
       - Settings screen: "Download my data" (JSON export ng posts, dm, etc.)

------------------------------------------------------------------------
2. EXPLORE / DISCOVERY (BIG ENGAGEMENT GAP)
------------------------------------------------------------------------
Search screen exists pero walang "Explore" mood. Without explore tab,
hindi ma-discover ng users ang content beyond followed accounts.

   2.1 Explore tab
       - Bagong root tab or section ng search_screen
       - Mixed grid: trending posts, popular reels, suggested users
       - Algorithm: weight by likes, comments, recency, sa user's region

   2.2 Trending hashtags list
       - "Trending now" section sa hashtag_screen
       - Backend: query top hashtags from last 24h / 7d

   2.3 Suggested users (beyond home rail)
       - Dedicated suggestions screen
       - Mutual followers, similar interests, location-based

   2.4 Onboarding interest picker
       - After signup: ask 3-5 interests / topics
       - Use yan to seed initial feed + suggestions

------------------------------------------------------------------------
3. CONTENT CREATION (NICE-TO-HAVE)
------------------------------------------------------------------------
   3.1 Post drafts
       - Auto-save sa local storage habang nag-co-compose
       - "Drafts" entry sa profile or create flow

   3.2 Polls
       - Bagong post type: question + 2-4 options
       - Vote count, end time, results view

   3.3 Scheduled posts
       - Pick future date/time when posting
       - Backend cron or scheduled jobs sa /home/ubuntu/katsklub server

   3.4 Story highlights
       - Save stories permanently sa profile as named collections
       - Visible sa profile bago featured photos

   3.5 Close friends list
       - User builds a list; stories can be posted "close friends only"
       - Green ring sa story avatar (Instagram style)
